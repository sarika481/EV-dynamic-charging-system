# EV-dynamic-charging-system
# IoT-Based Solar EV Charging System

## 📌 Overview
This project presents a smart EV charging system powered by solar energy with IoT monitoring.

## ⚡ Features
- Solar-powered EV charging
- Automatic switching (Solar + Grid)
- Real-time monitoring using IoT
- Remote control via mobile/web

## 🔧 Components
- Solar Panel
- Battery
- Arduino / NodeMCU (ESP8266)
- Relay Module
- Voltage Sensor
- Current Sensor

## 🔄 Working
1. Solar panel generates electricity
2. Energy stored in battery
3. EV charges using solar energy
4. If solar is low → switches to grid
5. IoT sends data to cloud

## 🌐 IoT Platform
Blynk / ThingSpeak

## 📱 Output
- Battery level
- Charging status
- Power usage

## 🚀 Future Scope
- AI optimization
- Wireless charging
